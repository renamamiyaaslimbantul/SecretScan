# Changelog

## 0.1.0 - 2026-09-23

Initial Windows-first release candidate.

- Recursive local scanning with configurable ignores
- GitHub, AWS, Google, JWT, private-key, database, API-key, password, and access-token detection
- Entropy and context-aware confidence scoring
- Redacted text and JSON output
- Git staged-file scanning through a Windows-compatible pre-commit hook
- YAML configuration and custom detection rules
- Windows 10/11 executable build
